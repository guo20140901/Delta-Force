【这一版把上次 demo 的三项并进正式版了】

1. 开镜（右键 / 手机右侧「开镜」按钮）
   六把枪倍率不同：Vector 1.42× / M4A1 1.30× / AKM 1.24× / M250 1.20× / M870 1.12× / SR-25 1.78×。
   镜筒有圆形压暗、亮线分划、密位刻度、倍率文字和实时测距；按下右键的那一瞬间以准心为锚点放大，
   实测瞄准点漂移 0.0–0.1px（以前会漂十几米）。开镜时移速 ×0.55，散布大幅收窄。

2. 后坐力
   每发枪口上跳 + 水平随机抖动，腰射只有开镜的 55%；停火后用临界阻尼弹簧回正，0.35 秒归零，不是瞬回也不是线性插值。
   准心会跟着上跳，松手自己滑回原位。

3. 拉栓 / 换弹动画
   M870 每发 0.62 秒泵动（护木前后滑 8px + 抛壳），SR-25 每发 0.16 秒拉机柄，动作期间打不出第二发。
   换弹：枪身下沉 9px + 旋转 0.30rad + 玩家头顶环形进度 + 换弹时长按弹匣容量算（1.15 + 弹匣×0.032，泵动 +0.7s）。

4. 射程重做：1 米 = 30 像素
   全项目统一 PPM=30：射程、投掷落点米数、地图距离标注、训练场靶距全部按这个换算。
   子弹速度 = 700 + 面板初速×1.45，子弹寿命 = 优势射程 ÷ 弹速，刚好飞满射程就消失，不再固定 1.4 秒。
   M4A1 40m=1200px、SR-25 60m=1800px、M870 12m=360px。

5. 干员物资箱可以背起（正式版按 Z，demo 里是 E）
   走到阵亡干员的战利品箱旁，按 Z 出 1.15 秒打包动画，完成后箱子从地面消失、挂在玩家背后、计入负重；
   再按 Z 放下。负重上限 26kg，每 kg 降 1.2% 移速（下限 55%），准心下方实时显示当前负重。
   靠近物资箱时交互提示会直接写「按 Z 背起 xx kg」。

6. 手机端
   右下新增「开镜」「背箱」两个按钮，开镜是按住式。触屏没点过画布时锚点取屏幕中心，不会把镜头甩到左上角。

【没变的】

武器还是 6 把（M4A1 / Vector / AKM / M870 / SR-25 / M250），物资表不含核电站专属物品；
体力走动 −1/s、疾跑 −2/s、静止 +1/s，疾跑 ×2、外骨骼 ×1.5；
打开背包 / 地图 / 药品轮盘只锁输入不锁时间；未登录进度写 localStorage。
