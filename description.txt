三角洲 2D 搜打撤

一款单机俯视角搜打撤游戏。选择红狼、露娜、牧羊人或蜂医进入战场，搜索物资、击败敌人，从拉闸撤、常规撤离点或狗牌撤带出战利品，换取哈夫币。


一、干员与技能

技能键统一为 Q 功能 / F 发射 / G 投掷，不再与 R 换弹冲突。

红狼（突击）：Q 外骨骼机甲 / F 三连装手炮 / G 烟雾弹 / Shift 滑铲
露娜（侦察）：Q 电击箭 / F 侦察箭 / G 破片手雷 / 持弓带弦
牧羊人（工程）：Q 声波陷阱 / F 声波威慑 / G 破片手雷 / 声波发射器
蜂医（支援）：Q 激素枪 / F 烟幕无人机 / G 蜂巢烟雾 / 药瓶激素枪

· 三连装手炮连射三轮，每轮一发，间隔 0.1 秒，同一直线无散射；专属模型右手持炮、左臂托管。
· 烟雾弹以落点为中心向外扩散，持续 5 秒以上。
· 烟幕无人机是独立实体：使用后屏幕下方出现白色电量条，3 秒内往中间收缩，鼠标控制飞行方向；电量耗尽在当前位置释放烟幕，整机不会被击落。


二、地图

· 西行政楼：开左、上、南三处门洞，东墙封死。
· 东行政楼：开右、上、南三处门洞，西墙封死。
· 楼内各有主厅、经理室、医疗室、警备室，全部留有门洞。
· 集装箱区位于中央通道，三段竖排：上段红色北开口内含航空箱，中段蓝色东开口内含小保险，下段红色南开口内含中武器箱，是夺舍流敌人的伏击点。
· 另有军营与两座补给站散布在野外。


三、对局

· 普通 / 机密 / 绝密三档，分别投入 8 / 12 / 16 名敌方干员，电脑掉落上限依次为金、紫、红。
· 五种稀有度物资：绿、蓝、金、紫、红。容器按类型掉落对应类别——武器箱只出弹药箱，医疗柜只出药品，电脑只出电子件，保险箱只出贵重品，航空箱全类别；不同容器搜索耗时不同。
· 敌方干员会搜物资、交战、拉闸、撤离，随机执行清图、跑刀、夺舍三种目标；搜刮期间不会主动开火，受击或搜完才进入战斗；血量低于 60% 会停下打药，死亡后掉落未用完的药与武器。
· 首领赛伊德固定刷新在东行政楼主厅，带两名精英副官。
· 小地图显示声纹与被标记敌人；按 M 键打开战术地图，查看建筑、撤离点与首领刷新点。
· 局内按 B 查看背包总价值与战损，按 H 打开药品转盘选择 238 / 532 / 836 血包，死亡会丢失携带物资与非基础武器。


四、创意工坊

已接入 VibeHub 创意工坊（loader v1），开放 14 项 Mod 能力：注册武器、读取武器、注册 / 应用 NPC 模板、读取 NPC、地图装饰、读取玩家、玩家回血、伤害钩子、子弹钩子、搜索产物钩子、订阅事件、广播事件、只读游戏数据。自定义小队生成通过 npcs.apply-to 的 spawnSquad 提供。

v3.2 起游戏内置四方阵营（玩家 / 阿萨拉 / GTI / 哈夫克），敌对关系对称，子弹按射手阵营结算——也就是说 Mod 造出来的新势力会真的和阿萨拉、干员、首领打起来，而不只是站着摆造型。其中 GTI 保留内战：干员之间、干员与玩家都会交火，阿萨拉与哈夫克内部则保持友好。

· Mod 分两个阶段加载：启动前注册武器 / 模板 / 装饰，启动后挂运行时钩子。
· 平台事件覆盖 round:start、round:end、extract、kill、death、damage、loot:taken。
· 未启用 Mod 时玩法与 v3.0 完全一致。
· 开发规范见作品工坊页的《Mod 开发指南》。


五、武器与近战

· 六把主武器各有俯视模型：M4A1 用伸缩托、平顶导轨红点与 A2 消焰器，AKM 用木质托与弧形弹匣，Vector 是方盒机匣加超 V 弹匣，M870 是长枪管与管式弹仓，SR-25 有抬高一层的高倍镜与 M-LOK 护木，M250 带提把、弹链盒与两脚架。枪身整体前移，护木到枪口完整露在躯干之外；角色朝左时自动镜像，不会倒着握枪。
· 三把近战刀是三套独立模型：战术匕首（双刃、护手）、黑鹰（黑涂层、转轴、背夹）、北极星（蓝钢、血槽、clip-point）。伤害 30 / 60 / 100，冷却 0.34 / 0.30 / 0.19 秒，北极星走攻速流，挥得快、爆发高。
· 挥砍分后摆、下劈、收势三段，刀身带残影，地面扫出白色刀光弧线，命中溅出火花。
· 干员平 A 统一用制式步枪，弓、激素枪、手炮只在技能期间出现在手上；切枪与投掷各有一段短动画。


六、撤离

· 拉闸撤：拉闸后等待 30 秒开闸，不限人数。
· 常规撤离点：最多 2 人。
· 狗牌撤：最多 3 人。

单机游玩，无需联机。登录后可保存哈夫币、仓库、武器与设置。

八、手机端与训练场（v6）

· 手机端：左下虚拟摇杆移动，右侧半屏拖动瞄准并持续开火；互动、换弹、近战、背包、地图各有独立按钮，技能栏可以直接点。窄屏下侧栏收成底部标签栏，主页、出击准备、交易行、仓库都改成单列可滚动，横屏竖屏都能玩。
· 战术地图右侧可以按箱型勾选物资箱，勾选后地图与小地图同步按等比例标出实时位置，已搜过的箱子显示为半透明。
· 设置里可以调小地图大小（70% 到 200%），也可以改全部键位：上下左右、互动、换弹、近战、血包、背包、地图、滑铲、三个技能与训练弹开关。点键位再按新键即可，右键键位恢复默认。
· 出击准备新增训练场，免费训练，不消耗物资与弹药。
· 训练场下方是一条长走廊，上方三个房间各开一个门洞：从左到右分别是近战训练场、射击训练场、躲避训练场。
· 近战训练场有一台 100 血的训练假人，可以攻击，打空后变灰并显示复活倒计时，3 秒后复活。
· 射击训练场有一张长桌，限制移动但子弹可以正常穿过；3m / 5m / 10m / 20m 四个距离牌由近及远排列；桌边电脑可以调整假人距离、是否左右移动与移动速度。
· 躲避训练场按 T 键开启或关闭训练弹发射器，训练弹命中只闪红边、不掉血。
· 三个房间各有一张桌子、一台电脑，可以选择干员与武器，直接调用仓库里已有的装备。
· 走廊最左右两端各有一个撤离点，站满 3 秒直接回主界面，不显示撤离结算界面。
· 击杀播报分流：只有玩家亲手击杀才从屏幕下方弹出，所有阵亡（包括自己击杀的）汇总显示在右上角。

十、道具与技能表现强化（v6 强化）

投掷物（破片手雷 / 烟雾弹 / 磁吸炸弹 / 刀片刺网 / 致盲毒雾 / 虎蹲炮炮弹）全部补齐专属模型 + 抛物线弹道 + 地面阴影 + 虚线轨迹；磁吸炸弹吸附后带 1 秒引信闪。所有发射类技能（三连装手炮 / 虎蹲炮 / 多功能钩爪枪）统一为「按技能键切专属武器 → 左键发射 → 打完自动切回原武器 → 再按一次技能键收起」，0.28 秒切枪动画，技能栏持械高亮。所有设备电量条统一到屏幕下方居中（仿生机械鸟 / 间谍摄像头 / 医疗无人机 / 烟幕无人机）。进入设备视角叠加信号画面：扫描线、噪点、暗角、四角取景框、REC 与 SIGNAL 角标，切换瞬间强干扰。每个技能释放都有 0.4 秒动作帧与主题色能量环。使用血包改为 2.2 秒打药过程（蹲姿、扎针动作、脚下进度环、按进度回血）。防爆套装带整套装甲外观（肩甲 / 胸甲 / 面罩 / 金边）。每个室内房间有专属家具组合与中央特色摆设（经理室会议桌、医疗室货架、警备室桶阵、军营篷布堆等）。交易行价格每分钟在原价基础上浮动 10%~30%（武器 / 弹药 / 药品 / 刀具 / 物资各自独立），仓库按件单独出售并显示交易行现价，局内物资显示参考价（原价）。


十一、操作手感与节奏（本轮）

· 疾跑速度 = 基础 ×2；外骨骼机甲、肾上腺素等加速类道具一律 ×1.5，与疾跑取最高值不叠乘。
· 增益期间不消耗体力；体力条仍然只显示条，不显示数值。

十八、修复（v10）

· 「受击自动弹出搜索界面」：该设置项与逻辑已彻底移除，站在物资旁被打不会再自动开箱。
· 「吃包 / 打药时时间暂停」：打开背包、战术地图、药品轮盘时只锁输入，AI、子弹、撤离倒计时照常推进。
· 退出训练场时配置面板遮罩残留，会拦截所有点击，现已在 exitTraining 中一并关闭。
· 未登录存档：wallet / stash / weapons / knives / ammo / meds / settings / tutorial 全部写 localStorage。

十九、手感测试场（demo-v10.html）

单独一页，进图即可玩，不需要存档数据。测四件事：

| 项目 | 操作 | 预期 |
|---|---|---|
| 开镜 | 右键 | 镜筒 + 分划 + 倍率 + 测距，六把枪倍率不同，准心锚定不漂 |
| 后坐力 | 按住左键 | 枪口上跳、腰射只有开镜 55%、松手 0.35s 平滑回正 |
| 拉栓 / 换弹 | M870 开火、按 R | 护木前后滑 8px + 抛壳 0.62s；换弹枪身下沉 + 头顶进度条 |
| 背箱 | 走到尸体旁按 E | 1.15s 打包动画，负重越高越慢，G 放下 |
| 体力 | Shift / Q | −1 / −2 / +1，疾跑 ×2，外骨骼 ×1.5 |

右下角面板可实时调后坐力强度、回正速度、腰射比例、开镜倍率，调好再反馈。
二十、开镜与后坐力（v11 正式版）

| 项目 | 口径 |
|---|---|
| 开镜键 | 鼠标右键按住；触屏为右下「开镜」按钮（按住式） |
| 倍率 | Vector 1.42× / M4A1 1.30× / AKM 1.24× / M250 1.20× / M870 1.12× / SR-25 1.78× |
| 过渡 | `ads` 0→1，`dt×12` 平滑，约 0.2 秒 |
| 锚点 | 按下瞬间锁定准心世界坐标，相机围绕它缩放；实测漂移 ≤0.1px |
| 移速 | 开镜期间 ×0.55，并禁止移动改朝向 |
| 镜筒 | 圆形压暗 + 亮线分划 + 密位刻度 + 倍率 + 测距；半径 `min(视口)×(0.21+0.10×ads)` |
| 玩家标记 | 镜内淡蓝小圈；被镜头甩出屏幕时屏幕边缘给方向箭头 |

后坐力：`kick=(1+(50-rec)/55)×26×枪型系数`，腰射 ×0.55；临界阻尼弹簧 `K=170`、`D=2√K`，0.35 秒归零。

· 键位 `Z`（可在设置里改），demo 内为 `E`。
